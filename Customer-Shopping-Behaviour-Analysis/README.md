⭐ Customer Shopping Behaviour Analysis

A Python-based data analytics project focused on analyzing customer purchasing patterns, shopping preferences, and consumer behaviour. The project involved data cleaning, exploratory data analysis (EDA), and data visualization to identify meaningful trends and generate actionable business insights.

🛠️ Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
