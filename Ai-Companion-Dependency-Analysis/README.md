⭐ AI Companion Dependency Analysis

📌 Project Overview

A Python-based data analytics project exploring AI companion usage patterns and their relationships with social interaction, lifestyle factors, emotional well-being, and dependency risk.

🛠️ Tools & Technologies

• Python

• Pandas

• NumPy

• Matplotlib

• Seaborn

• Jupyter Notebook

📊 Key Activities

• Performed data cleaning and feature engineering to prepare the dataset for analysis.

• Conducted Exploratory Data Analysis (EDA) to identify patterns in AI companion usage and dependency risk.

• Developed data visualizations to explore relationships between behavioral, social, and emotional factors.
